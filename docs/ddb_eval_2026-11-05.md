# Full run on the local DuckDB files, 2026-11-05

All five benchmarks in all three settings, run from `../data/decode-join-duckdb` (now the default in `src/duckdb_driver.py`). Stages 1–4 use run names `ddb`, `ddb_low`, `ddb_full` and `ddb_joins_only`. Raw rows are in `out/eval/ddb/`.

Settings: teammate's defaults (quantile-EMD term, G9 off, cap at d < 0.3), glm-5-3 at low reasoning, grouped adjudication. Obfuscated variants use the no-names weights.

## Notes

- The pipeline reads no declared constraints, so documented and stripped give the same joins and, apart from small noise on FIBEN, the same scores.
- `joins_only` (no descriptions) with bge, best PR@15: obfuscated BIRD .945, BEAVER .167, FIBEN .427. Descriptions lift these to .962, .367 and .620.
- On BEAVER dw the walk over pipeline joins scores .183 against .492 on JoinGR's graph, so the table above shows dense.
- BIRD and FIBEN results on the local files reproduce the 2026-11-04 scores.
- Spider and BIRD obfuscated results carry the memorization caveat from earlier probes.
- KaggleDBQA: the filter keeps only 4 of 8 databases (the rest have no multi-table questions). The other 4 were appended to `out/filtered/kaggledbqa*/databases.json` by hand so the retrieval pool matches JoinGR's; re-running the filter removes them.
- No LLM reply: FIBEN `DERIVATIVE` (documented, stripped), BEAVER obfuscated `FCLT_MAJOR_USE`. Those tables have no descriptions.
